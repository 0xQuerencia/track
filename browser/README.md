# Track Pulse Chromium prototype

Load this directory with developer mode / Load unpacked in Chromium. Create a dedicated activity:write integration token in Track Settings and pair using the server's HTTPS origin. Tracking is opt-in and sends only coarse observed intervals, never URLs, page titles, history or page content. The extension samples focused normal windows and idle state; intervals around transitions and worker suspension can be undercounted. It does not claim precise attention measurement. No incognito collection. Pause or disconnect from the popup; disconnect clears the local queue and credentials, but not records already sent to Track. Revoke the token separately on Track. Browser compatibility and end-to-end pairing require manual smoke testing. This is an initial collector; per-domain classification and blocking are not yet implemented.
