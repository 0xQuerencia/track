# Explicit private and AI Pod memory

Owner-authored memory notes belong to one namespace: personal, or a specific private AI Pod. Notes can link to a completed mission in that same namespace and optionally expire within one year. No automatic memory mining or social-pod access is enabled. A mission may attach up to six explicitly previewed notes. The exact redacted payload, namespace, revisions, expiry and consent are fingerprinted; edits, deletion, expiry, missing source, or changed consent stop subsequent provider requests and result commits. The mission never inherits another namespace's notes. Deleting a source mission erases its linked notes; deleting all Dreamer data clears notes and bindings. Old saved reports may retain prior derived information and require separate deletion. Individual specialist namespaces and automatic memory retrieval remain separate work.
