# Read-only research connectors

Opt in with TRACK_DREAMER_RESEARCH_ENABLED=1. Supported retrieval: Wikipedia search snippets, Crossref scholarly metadata and open GitHub issues/pull requests for exact repositories in TRACK_DREAMER_GITHUB_REPOS (comma-separated). An optional dedicated read-only TRACK_DREAMER_GITHUB_TOKEN is attached only to api.github.com; never use an owner-wide write token. No arbitrary URL fetching, redirects, model-generated requests, shell or third-party credentials. Network calls have fixed HTTPS origins, ten-second timeout, 1 MiB response cap, bounded result projection and no HTML execution. Returned links are reconstructed from validated IDs, never accepted as fetch targets.

Explicit research runs store local dated citations in one private namespace. Save selected results into memory and then explicitly review the excerpt before attaching to a mission. Model sees untrusted source text, not tool authority; no claims of full-article retrieval. Removing a research run removes linked memory notes; prior reports require separate deletion. No live upstream calls were made in tests. General web search, GitHub writes and continuous monitoring are follow-ups.
