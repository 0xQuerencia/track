# Local action capability boundary

The first action registry permits only a single task, local calendar event or note creation with strictly validated fields. It reuses the manual-record validation path and does not expose generic SQL, update, delete, shell, network, email, financial, or deployment capabilities. Each immutable draft belongs to a completed Chief report, has an exact SHA-256 approval, expires after 24 hours, and is bound to current AI consent. Approve or reject one draft; a retry returns its existing receipt. The create and receipt share an immediate SQLite transaction, so a retry cannot duplicate a record. Model output never grants authority. Scheduled missions cannot approve actions. Deleting a mission erases its draft metadata, not records the owner previously approved. Safe automated undo and external tools are not yet included; approved local records can be edited/deleted in their existing Track screens.
