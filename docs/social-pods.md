# Private persistent Pods

Create a pod, invite accepted friends using one-time recipient-bound expiring codes, and share the code privately. Only members may read a pod. Owner may appoint moderators, remove members, transfer ownership, or explicitly delete the pod. Moderators may invite and remove ordinary members but may not manage roles or remove owners/moderators. Members can leave; owners must transfer ownership or delete. Removal revokes access and pending invitations immediately. Existing group membership is not implicitly changed by a personal block; direct friendship and presence are still revoked. Later shared chat must suppress blocked participants' messages. Pods are not publicly discoverable; no private OS data is imported. API only, not a public-ready service.
