# Durable Dreamer executor

Read-only provider calls use the existing shared AI gate and static agent definitions. The objective and completed dependency reports are bounded and redacted; no tool execution, shell, web browsing, social data, or external action is available. Optional source context requires a SHA-256 approval of the exact current redacted excerpt set and consent scope; stale, edited, deleted or excluded sources invalidate the approval. No copy of the excerpts is stored in the approval table. Consent, agent status, approval and lease ownership are rechecked before transport attempts and completion. A request already sent cannot be recalled. Model outputs remain untrusted text; no model result can trigger an action. Provider retries/fallback may cause more HTTP requests than logical step attempts; reservations are not a monetary quota. The worker runtime and owner submission UI are separate follow-ups.
