# Social browser smoke gate

The Social CI now launches an isolated loopback service with an in-memory database and two independent Chromium browser contexts (desktop and mobile viewport). It exercises account enrollment, friend acceptance, recipient-bound Pod invite, shared task visibility, room creation/join, break chat, readiness, authoritative synchronized start, personal pause, group pause/resume and end. It checks JS page errors and horizontal overflow. It does not connect to the deployed Track instance or use real credentials. Local: install the pinned Playwright version in social, install Chromium, then run node browser-smoke/run.mjs. This is an automated functional smoke test, not a complete screen-reader, contrast, real-phone, multi-network, security, or browser-compatibility audit.
