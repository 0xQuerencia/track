# Pod room lifecycle
Rooms are visible only to pod members. Create a private lobby with explicitly entered objective and optional earliest start (within 30 days). The host starts after all joined members have checked ready and are recently connected. Scheduled time is a gate, not an automatic alarm. Members can join late, leave and rejoin; leaving never stops the group room. A 90-second heartbeat lease determines connectivity; a moderator can transfer host when the old host is disconnected, and a connected host can transfer voluntarily. Every host command is revision-checked. Pod removal immediately denies room reads and mutations. This is the persistent lobby/lifecycle layer; synchronized Pomodoro phases follow. No public rooms, voice, or video are exposed.
