# Local wordmark font

Place an appropriately licensed `DxBurst-Regular.otf` file in this directory to enable DX Burst on the landing page. The app falls back to Bricolage Grotesque when the file is absent.

The supplied ZIP's EULA restricts redistribution of the font and defines a separate Web Font license with domain and page-view limits. The font binary is therefore gitignored and is only present in this local development copy. Confirm the right license and add the approved font asset before deploying the DX Burst version.
